State Space Models, down to the scan

What an SSM is, why S4 and Mamba work, where SSMs are used, and a structural flaw in the standard Mamba parameterisation. I reproduce the flaw, fix it with a one-line change, and then make the fix run on Mamba-2's fast chunked algorithm, which the original authors left as future work.

1. The core equations

A state space model maps an input signal u(t) to an output y(t) through a hidden state x(t) of size N. The idea comes from control theory (Kalman, 1960). Deep-learning SSMs keep the same equations and learn the matrices.

x'(t) = A x(t) + B u(t) # state evolves linearly; A is N×N y(t) = C x(t) + D u(t) # readout + skip connection

Neural networks see tokens, not continuous time, so the system is discretised with a step size Δ. Zero-order hold (assume u is constant during each step) gives:

Ā = exp(ΔA) B̄ = (ΔA)⁻¹ (exp(ΔA) − I) · ΔB # Mamba simplifies this to B̄ ≈ ΔB h_t = Ā h_{t−1} + B̄ u_t y_t = C h_t + D u_t

Δ matters more than it looks. A small Δ makes Ā ≈ I, so the state holds on to the past and mostly ignores the current input. A large Δ makes Ā ≈ 0, so the state resets and takes in the current token. Selective SSMs work by learning to set Δ per token.

Stability needs the eigenvalues of A to have negative real part, so the eigenvalues of Ā lie inside the unit circle. Almost every modern SSM keeps A diagonal and negative real: A = −exp(A_log). That means each eigenvalue of Ā is a number in (0, 1). Section 8 shows why this is a problem.

2. One model, three views

If A, B, C and Δ do not depend on the input (a linear time-invariant, or LTI, system), the same model can be computed in three equivalent ways. S4's main trick is switching between them.

RecurrentStep h_t = Āh_{t−1} + B̄u_t. O(1) memory and compute per token. Used for inference, with no KV cache that grows with context.
ConvolutionalUnroll the recurrence: y = K * u with kernel K = (CB̄, CĀB̄, CĀ²B̄, …). Computed with an FFT in O(L log L). Used for parallel training.
ContinuousThe model is defined on t, not on token index. Changing Δ resamples it, so a model trained at 16 kHz can run at 8 kHz.
# proof of the convolution view (h_{−1} = 0) h_0 = B̄u_0 h_1 = ĀB̄u_0 + B̄u_1 h_2 = Ā²B̄u_0 + ĀB̄u_1 + B̄u_2 y_k = Σ_j C Ā^{k−j} B̄ · u_j = (K * u)_k

3. Lineage: from HiPPO to Mamba-3

2020

HiPPO. Asks which A makes the state an optimal running compression of the whole history. Projecting onto Legendre polynomials gives a specific A matrix, and initialising with it fixes the forgetting problem of random linear RNNs.

2021

S4. HiPPO A as a diagonal-plus-low-rank (DPLR) matrix, with a Cauchy-kernel algorithm to compute the convolution kernel quickly. First model to solve Path-X (sequence length 16k) in Long Range Arena.

2022

DSS / S4D / S5. A purely diagonal A works about as well as DPLR. S5 uses one multi-input multi-output SSM and a parallel scan instead of a convolution, which later makes Mamba possible.

2023

H3, Hyena, RetNet, RWKV. Attempts to match attention on language. LTI models struggle with associative recall (the Zoology/MQAR results), because a fixed kernel cannot decide what to keep based on content.

Dec 2023

Mamba (S6). Makes Δ, B and C functions of the input. The model stops being LTI, so the convolution view is gone. A fused, hardware-aware parallel scan on GPUs replaces it. Matches Transformers of the same size on language up to a few billion parameters.

2024

Mamba-2 (SSD). Restricts A to a scalar times the identity. The layer then equals a masked linear attention, y = (L ∘ CBᵀ) x, and can be trained with matrix multiplies on tensor cores. 2–8× faster training. Hybrids follow: Jamba, Zamba, Samba, NVIDIA's Mamba-2-Hybrid, and later Nemotron-H and Falcon-H1.

2024–25

Expressivity results. The Illusion of State (Merrill et al.) shows SSMs with the usual parameterisation sit in the same circuit class (TC⁰) as Transformers, so they cannot track state in general. Grazzi et al. (ICLR 2025) show that eigenvalues restricted to [0,1] cannot solve parity, and that allowing [−1,1] fixes it. A 2025 follow-up shows that stacking LTI layers with non-negative selective layers does not help: one layer must be both input-dependent and allow negative eigenvalues. Gated DeltaNet and DeltaProduct add non-diagonal (Householder) transitions.

2026

Mamba-3 (arXiv, March 2026). Exponential-trapezoidal discretisation, complex-valued (rotational) state updates for state tracking, and a MIMO formulation that raises arithmetic intensity during decoding. All three aim at the expressivity and hardware-efficiency gaps above.

4. Selection and the parallel scan

Mamba's change is small to write and large in effect. For each token, a linear projection of the input produces the SSM parameters:

Δ_t = softplus(W_Δ u_t + b) # per channel: how much to write vs. keep B_t = W_B u_t, C_t = W_C u_t # what to write into the state, what to read out ā_t = exp(Δ_t · A) # A = −exp(A_log): ā_t ∈ (0,1) h_t = ā_t ⊙ h_{t−1} + Δ_t B_t u_t y_t = C_tᵀ h_t + D u_t

The model can now ignore a filler token (Δ → 0, the state passes through unchanged) or reset on a delimiter (Δ large, the state is overwritten). An LTI model cannot do either.

There is no fixed kernel anymore, so how does training run in parallel? The recurrence h_t = a_t h_{t−1} + b_t is a composition of affine maps, and composing affine maps is associative:

(a₁, b₁) • (a₂, b₂) = (a₁·a₂, a₂·b₁ + b₂)

An associative operator can be computed with a Blelloch prefix scan in O(log L) parallel steps. Mamba's CUDA kernel does this in SRAM and never writes the expanded (B, L, D, N) state tensor to HBM. Note that associativity holds for any real a_t, including negative values. That fact matters in sections 8 and 9.

Mamba-2 goes further. Unroll the recurrence and the output is a matrix product with a lower-triangular 1-semiseparable mask:

y = M x, M_ij = C_iᵀ B_j · (a_{j+1} · a_{j+2} ⋯ a_i) for i ≥ j = (L ∘ C Bᵀ) x # L_ij = Π a → "linear attention with decay"

This is the state space duality. Attention computes softmax(QKᵀ)V. An SSM computes a structured mask times CBᵀ times x, where C plays the role of Q and B plays the role of K. In practice Mamba-2 computes log L_ij as a segment sum of log a_t, which only works if every a_t is positive.

6. Known limits of current SSMs

  1. Fixed-size memory. All history is compressed into N·D numbers. Copying a long string or retrieving a phone number from 100k tokens back fails once the information exceeds that state (Jelassi et al., Repeat After Me, 2024). Transformers keep every token in the KV cache. This is the main reason production models are hybrids with a few attention layers.
  2. State tracking. Tasks like parity, permutation composition, or following code variables through reassignments need the state to rotate or flip, not just decay. With real diagonal ā_t ∈ (0,1), each channel can only shrink toward zero and add. Sections 7–8 show this directly.
  3. Length generalisation. Δ and the effective memory horizon are learned at training lengths. Beyond them, models often degrade (cf. LongMamba, DeciMamba).
  4. Hardware fit. Scans are memory-bound, while GPUs are built for matrix multiplies. Mamba-2's SSD and chunked kernels close most of this gap, at the cost of the restrictions above (scalar A, positive decay).

7. Playground: why (0, 1) cannot count

This is one channel of a selective SSM solving parity, the simplest state-tracking task. The state starts at h = 1. Each bit selects a decay ā: bit 0 gives ā = 1 (keep), bit 1 gives whatever value the model can produce. Click the bits to flip them.

Bit-1 decay range:
state h_ttrue parity (+1 even, −1 odd)

In standard mode the state stays positive and only shrinks: after k ones it equals ā^k. Odd and even counts interleave on that single decreasing scale (ā¹ > ā² > ā³ …), so no fixed threshold separates them. The output layer would have to read parity from the exact magnitude ā^k. That works for small k but the levels collapse below float resolution as k grows. In negative mode ā = −1 makes h = (−1)^k exactly: one sign bit, correct at any length. Real Mamba also mixes channels with nonlinearities between layers. Grazzi et al. prove that a finite-precision linear RNN with only non-negative eigenvalues still cannot solve parity at arbitrary length. That is the result tested below.

8. Experiment: fixing Mamba's eigenvalue range

I implemented a 2-layer Mamba-style selective SSM in PyTorch (d_model 32, expand 2, state size 8, gated output, pre-LayerNorm residual) and trained it to output the running parity of a bit string. The two variants differ in one line:

a = torch.exp(-dt[..., None] * self.A_log.exp()) # standard Mamba: a ∈ (0,1) if self.neg: a = 2 * a - 1 # fixed: a ∈ (−1,1), same parameters, same init

Training: 1,500 AdamW steps, batch 64, lengths drawn uniformly from 3 to 40, loss on every position. Test: accuracy of the parity of the whole sequence on 256 fresh sequences at length 40 (in distribution), 128 and 512 (3× and 13× longer than any training sequence). Chance is 0.5. Three seeds each, CPU only.

The result is clear-cut. The standard model stays at chance (0.49–0.57) even on lengths it was trained on. The flipped-sign version is perfect on every seed, including sequences 13× longer than any it saw. This matches Grazzi et al.'s Table 3 (Mamba [0,1]: 0.000 vs [−1,1]: 1.000 on their normalised scale) with a 24.5k-parameter model trained on one CPU core in about 5 minutes per run.

What the fix costs

  • Parameters and FLOPs: none. It is an affine remap of a value the layer already computes.
  • Parallel scan: still valid, because the affine-composition operator is associative for any real a_t.
  • Kernels: this was the real cost. Mamba-2/SSD computes decay products as exp(cumsum(log a)), which returns NaN for a < 0. Grazzi et al. name this as a limitation: they patched Mamba-1's CUDA scan by hand and left log-space models to future work. Section 9 removes the problem without touching the kernel.
  • Language modelling: mixed. In Grazzi et al.'s 370M-parameter runs, the [−1,1] Mamba trained stably but had slightly worse perplexity (Wikitext 24.84 → 25.02) and worse perplexity on code and math. The gains are concentrated in state-tracking tasks. It also does nothing for recall-heavy tasks; that is limit 1 above, a separate problem.
  • What it does not fix: diagonal transitions with negative entries can represent abelian, sign-flip structure (parity, modular counting by 2). Non-abelian tasks such as composing permutations of 5 elements still need non-diagonal transitions: products of Householder reflections (DeltaProduct) or the complex rotations of Mamba-3.

9. Signed SSD: the fix at Mamba-2 speed

Mamba-2 trains fast because its chunked SSD algorithm turns the scan into matrix multiplies. It builds the decay mask as exp(segsum(log a)). A negative a has no real logarithm, so feeding the fix from section 8 into the stock algorithm gives NaN in 100% of outputs (tested below). Grazzi et al. list this as a limitation and leave it to future work. Combining three facts already on this page removes the problem.

Gauge lemma. Let s_t = sign(a_1)·sign(a_2)⋯sign(a_t) ∈ {+1, −1} and define the re-signed state h̃_t = s_t h_t. Since s_t a_t = |a_t| s_{t−1}:
h̃_t = |a_t| · h̃_{t−1} + (s_t x_t) B_tᵀ # an ordinary positive-decay SSM y_t = s_t · (h̃_t C_t) ⇒ SSD_signed(a, x) = s ⊙ SSD_positive(|a|, s ⊙ x)
In the matrix view of section 4, the signed semiseparable mask factorises as L_signed = diag(s) · L_|a| · diag(s), because the sign of a product over a segment is s_i s_j. Every existing positive-only kernel (Mamba-2 Triton, CUDA Tile, chunked FLA kernels) can run negative eigenvalues unchanged, with one cumulative sum before and two sign flips around it.
def ssd_signed(x, a, B, C, chunk=64): neg = (a < 0).long() s = 1 - 2 * (neg.cumsum(1) % 2) # running sign, exact integers log_abs = torch.log(a.abs().clamp_min(tiny)) return s[..., None] * ssd_positive(x * s[..., None], log_abs, B, C, chunk)

The signed SSD model learns parity every time; the positive one never does, even in distribution. Length generalisation is weaker than in section 8: the best runs hold to 4× training length and then fail. My working hypothesis is that with only one decay per head, the learned |a| for "keep" and "flip" tokens ends up close to 1 but not equal to it, so the state magnitude drifts over thousands of steps. The section 8 model has 512 independent decays per layer and more chances to land one exactly on ±1. A 16-head run reached 0.78 at L = 256, which is not enough evidence either way. This is the main open question from this work.

10. What to build next

  1. Drop the gauge into a real GPU kernel. Wrap mamba_chunk_scan_combined from mamba_ssm with the three lines above and train a 130M–370M model with a = 2·exp(Δ·A) − 1. This tests the fix at scale at Mamba-2 speed, which Grazzi et al. could not do.
  2. Make |a| = 1 reachable. Parameterise sign and magnitude separately (for example, magnitude in log-space pinned near 0, sign from a separate gate) so a "flip" can be exactly −1 without Δ → ∞. This targets the extrapolation gap above.
  3. Hybrid for recall. Roughly one attention layer per 6–8 signed-SSD layers handles retrieval, which fixed-size state cannot. Test MQAR (recall) and S5 permutation or modular arithmetic (state tracking) on the same model.
  4. Beyond abelian. Sign flips cover parity-like structure. Composing permutations needs rotations or Householder products (Mamba-3, DeltaProduct). The gauge idea extends to any transition group with a cheap prefix product, which is worth working out for complex phases.
